</div>

|:---------|:--------:|

By working through this repository, I aim to:

- 🧠 Build **strong JavaScript fundamentals** with daily hands-on practice
- 🔒 Understand **closures, scope, and higher-order functions** deeply
- 🎯 Master **array methods** (map, filter, find, forEach, reduce)
